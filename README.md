# Бриф сайта вратарского тренера

Две рабочие страницы для согласования с клиентом. Не для публичного распространения.

- `index.html` — анкета: 45 вопросов, автосохранение в браузере, сборка ответов в текст одной кнопкой
- `napravleniya.html` — три визуальных направления сайта на выбор

Страницы самодостаточные: весь CSS и JS внутри файла, снаружи подключаются только шрифты Google Fonts.
Обе закрыты от поисковиков через `meta robots` и `robots.txt`.
